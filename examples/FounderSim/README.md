# FounderSim - Web 创业模拟器

一个在浏览器里运行的轻量级创业模拟游戏，通过简化的资金、用户、产品进度、团队士气等指标，模拟从 0 到 1 创业的关键抉择与随机事件。

## 运行方式

- **直接打开**：用浏览器打开 `index.html` 即可开始游戏（建议使用最新版 Chrome / Edge）。
- **本地静态服务器（可选）**：
  - 使用 VS Code Live Server 插件，右键 `index.html` 选择「Open with Live Server」；
  - 或者使用任意静态服务器（如 `npx serve`），将根目录作为站点根路径。

## 核心玩法

- 每回合代表 **1 个月**，总共 36 个月；
- 你需要在现金、用户、产品进度、团队士气之间权衡：
  - 打磨产品、拉新获客、融资路演、招聘人才、精细运营、战略转型（Pivot）；
- 游戏内含一部分随机正/负事件：
  - 自来水传播、共创迭代、成本优化、线上事故、团队波动、外部环境变化等。

## 技术栈

- 纯前端静态页面：`HTML + CSS + 原生 JavaScript`
- 无第三方依赖、无后端，所有状态都在浏览器本地内存中运行。
