# 工作玩法重新设计

## 一、需求分析

### 1.1 当前问题
- 工作行动选项较少（只有3个）
- 资金积累途径单一（只有月薪和奖金）
- 属性提升途径有限（只有自主学习）
- 缺乏长期目标和职业发展路径
- 工作体验较为单调

### 1.2 设计目标
- 增加更多行动选项，提供更多策略选择
- 增加资金积累途径（绩效奖金、年终奖、项目奖金、副业等）
- 增加属性提升途径（培训、技能提升、工作经验等）
- 添加技能系统和职业发展路径
- 增加工作成就和里程碑系统

## 二、新功能设计

### 2.1 扩展行动选项

**新增行动**：
1. **加班**：消耗精力，获得额外奖金（基础奖金 × 1.5-2倍）
2. **社交**：消耗沟通，获得人脉值，可能触发机会事件
3. **培训**：花费金钱，提升指定属性（5000-20000元，属性+2-5）
4. **副业**：消耗精力，获得额外收入（2000-5000元/月）
5. **跳槽**：寻找更好的工作机会（需要满足条件，可能获得更高薪资）

**保留行动**：
- 努力板砖（优化奖励）
- 偷偷摸鱼（优化奖励）
- 自主学习（优化奖励）
- 辞职

### 2.2 技能系统

**数据结构**：
```javascript
player: {
    skills: {
        technical: 0,      // 技术技能（0-100）
        management: 0,     // 管理技能（0-100）
        sales: 0,         // 销售技能（0-100）
        communication: 0  // 沟通技能（0-100）
    },
    skillPoints: 0        // 技能点（通过工作积累）
}
```

**技能获取**：
- 通过工作行动积累技能点
- 不同行动获得不同技能点
- 技能影响工作表现和收入

### 2.3 职业发展系统

**职业路径**：
- 每个工作有明确的职业发展路径
- 达到条件可以晋升或转职
- 不同路径有不同的奖励

**晋升条件**：
- 工作年限
- 技能等级
- 属性要求
- 工作表现（绩效评分）

### 2.4 资金积累系统

**新增收入来源**：
1. **绩效奖金**：每月根据工作表现获得（0-5000元）
2. **年终奖**：工作满12个月获得（月薪 × 2-5倍）
3. **项目奖金**：完成特殊项目获得（10000-50000元）
4. **副业收入**：通过副业行动获得（2000-5000元/月）
5. **跳槽加薪**：跳槽到更好工作获得更高薪资

### 2.5 属性积累系统

**新增属性提升途径**：
1. **培训课程**：花费金钱参加培训，提升指定属性
2. **技能转化**：技能等级可以转化为属性加成
3. **工作经验**：工作年限增加经验值，经验值可转化为属性
4. **工作成就**：完成特定成就获得属性奖励

## 四、关键数值设计

### 4.1 行动奖励

**努力板砖**：
- 奖金：1000-3000元
- 技能点：+2-5（技术/管理）
- 工作表现：+1-3

**加班**：
- 奖金：基础奖金 × 1.5-2倍
- 精力消耗：-5-10
- 技能点：+3-6（技术）
- 工作表现：+2-5

**社交**：
- 人脉值：+5-15
- 沟通消耗：-3-5
- 技能点：+2-4（沟通/销售）
- 可能触发机会事件

**培训**：
- 属性：+2-5（根据课程）
- 技能点：+5-10（根据课程）
- 花费：5000-20000元

**副业**：
- 收入：2000-5000元/月
- 精力消耗：-5-10
- 技能点：+1-3（根据副业类型）

### 4.2 技能系统

**技能点获取**：
- 努力板砖：+2-5技术/管理
- 自主学习：+2-4（根据属性）
- 加班：+3-6技术
- 社交：+2-4沟通/销售
- 培训：+5-10（根据课程）

**技能加成**：
- 技能每10点提供1%收入加成
- 技能影响工作表现
- 技能影响跳槽成功率

### 4.3 工作表现系统

**工作表现计算**：
- 基础值：50
- 努力板砖：+1-3
- 加班：+2-5
- 偷偷摸鱼：-1（有风险）
- 技能加成：技能等级 / 10

**工作表现影响**：
- 绩效奖金：工作表现 × 50元
- 晋升条件：工作表现 ≥ 70
- 年终奖：工作表现影响倍数
