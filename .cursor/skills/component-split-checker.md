# 组件拆分检查器

## 触发条件
当用户说“检查组件拆分”、“这个组件需要拆分吗”、“组件太大了”时触发。

## 执行步骤

1. **读取当前文件或用户选中的代码**

2. **按以下维度逐项检查并打分：**
   - 行数：>250行 → +1分；>400行 → +2分
   - 职责：存在数据请求 + UI渲染 + 多个业务逻辑 → +2分
   - 复用：同一段 JSX 重复 ≥2 次 → +1分
   - 嵌套：存在可以独立的功能块（如弹窗、表格、表单）→ +1分
   - props：接收 >8 个 props → +1分；存在 props 透传超过2层 → +1分

3. **输出决策：**
   - 0-2分：当前组件合理，无需拆分
   - 3-4分：建议拆分，附上具体建议
   - ≥5分：强烈建议拆分，并给出拆分方案

4. **拆分建议模板：**
   - 提取 `[功能名]` 为独立组件（理由：xxx）
   - 将数据请求逻辑抽取为自定义 hook `useXxx`
   - 建议的文件组织方式
