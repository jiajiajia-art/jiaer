## 实施步骤

1. **每处理一个文件前**，先在该文件对应的翻译文件中添加新的 key
2. **在组件中**：

- 如果已有 `useTranslation`，直接使用 `t('key')` 替换
- 如果没有，添加 `import { useTranslation } from 'react-i18next'` 和 `const { t } = useTranslation()`

3. **替换规则**：

- 用户可见文本：按钮、标签、提示 → 用 `t('key')`
- 代码注释、内部日志 → **不处理**

4. **翻译文件结构扩展**：

- `home`: 首页相关
- `galgame`: 游戏相关
- `create`: 创作相关
- `profile`: 个人中心相关
- `game`: 游戏详情
- `stGame`: ST 游戏
- `promotion`: 推广中心
- `admin`: 管理面板
- `errors`: 通用错误提示（跨文件复用）

## 注意事项

- 保持命名空间清晰，避免 key 冲突
- 动态文本（如 `已选择 ${count} 个草稿`）使用模板语法 `t('key', { count })`
- 验证 `npm run build` 通过后再处理下一个文件
