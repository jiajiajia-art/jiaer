# 游戏封面图文件夹

## 📁 文件夹说明

此文件夹用于存储游戏中心展示的**游戏封面图片**。

## 🖼️ 图片要求

### 尺寸规格
- **推荐尺寸**：800 x 800 像素（1:1 正方形）⭐
- **备选尺寸**：600 x 600、1000 x 1000、1200 x 1200 像素
- **最小尺寸**：400 x 400 像素
- **最大尺寸**：2000 x 2000 像素
- **比例要求**：正方形（1:1），游戏卡片会完整展示封面

### 文件格式
- ✅ **PNG** - 推荐，支持透明背景
- ✅ **JPG/JPEG** - 适合照片类图片
- ✅ **WEBP** - 现代格式，文件更小

### 文件大小
- 建议单个文件不超过 **500KB**
- 过大的图片会影响页面加载速度

## 📝 命名规范

封面图片应与游戏 ID 保持一致：

```
游戏ID.扩展名
```

### 示例

| 游戏 ID | 文件名 |
|---------|--------|
| `fantasy-world` | `fantasy-world.png` |
| `mystery-mansion` | `mystery-mansion.png` |
| `cultivation-journey` | `cultivation-journey.png` |

## 🎨 设计建议

### 视觉要求
1. **清晰度高**：确保图片清晰，不模糊
2. **主题突出**：封面应体现游戏主题和风格
3. **文字可读**：如果包含文字，确保在缩略图下也能看清
4. **色彩搭配**：与游戏氛围相符的配色方案

### 内容建议
- 游戏关键场景
- 主要角色形象
- 游戏世界观展示
- 游戏 Logo 或标题

### 避免事项
- ❌ 过于复杂的画面
- ❌ 文字过小难以辨识
- ❌ 色调过暗或过亮
- ❌ 与游戏主题不符

## ✏️ 如何添加新封面

### 步骤 1：准备图片
1. 设计或准备游戏封面图
2. 调整到推荐尺寸（800x800 正方形）⭐
3. 优化文件大小（推荐 < 500KB）
4. 保存为合适的格式（PNG/JPG）

### 步骤 2：命名文件
按照游戏 ID 命名文件，例如：
- 游戏 ID 为 `new-game`
- 文件命名为 `new-game.png`

### 步骤 3：放置文件
将图片文件放入此文件夹：
```
StoryData/covers/new-game.png
```

### 步骤 4：更新配置
在 `StoryData/games.json` 中设置封面路径：
```json
{
    "id": "new-game",
    "cover": "StoryData/covers/new-game.png",
    ...
}
```

## 📐 尺寸参考

### 显示位置及尺寸

1. **游戏卡片封面**
   - 显示比例：1:1 正方形
   - 显示方式：完整展示，不裁剪
   - 背景色：浅灰色（#f5f5f5）

2. **详情弹窗封面**
   - 显示尺寸：800px 宽度，300px 高度
   - 显示方式：自动裁剪，居中显示

3. **响应式适配**
   - 移动端会自动缩放
   - 保持正方形比例

## 💡 制作技巧

### 技巧 1：正方形设计
设计时考虑正方形构图，将关键元素放在中心区域

### 技巧 2：使用游戏场景
从游戏的场景图片中选择代表性画面作为封面

### 技巧 3：添加文字信息
在封面上添加游戏标题、副标题等信息（居中效果最佳）

### 技巧 4：统一风格
保持所有游戏封面的设计风格统一

### 技巧 5：测试效果
在正方形画布中查看封面效果，确保关键信息可见

## ⚠️ 注意事项

1. **版权问题**
   - 确保使用的图片有合法使用权
   - 避免使用未授权的版权图片

2. **文件命名**
   - 使用小写字母和连字符
   - 不要使用空格或特殊字符
   - 与游戏 ID 保持一致

3. **兼容性**
   - 建议使用 PNG 或 JPG 格式
   - WEBP 格式在旧浏览器可能不支持

4. **备份**
   - 保留原始高清图片
   - 定期备份封面图片
