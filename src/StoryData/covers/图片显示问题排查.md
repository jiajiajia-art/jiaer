# 图片显示问题排查指南

## 🔍 常见问题及解决方案

### 问题 1：浏览器缓存
**症状**：替换图片后仍显示旧图片或不显示

**解决方案**：
1. **强制刷新页面**
   - Windows: `Ctrl + F5` 或 `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`
   
2. **清除浏览器缓存**
   - Chrome: `Ctrl + Shift + Delete` → 选择"图片和文件" → 清除数据
   - Firefox: `Ctrl + Shift + Delete` → 勾选"缓存" → 清除

3. **使用隐私/无痕模式**
   - 按 `Ctrl + Shift + N` (Chrome) 或 `Ctrl + Shift + P` (Firefox)
   - 重新打开 StartGame.html

### 问题 2：图片格式或损坏
**症状**：图片完全不显示或显示损坏图标

**解决方案**：
1. **检查图片格式**
   - 支持格式：PNG、JPG/JPEG、WEBP
   - 不支持：BMP、TIFF、PSD 等

2. **重新保存图片**
   - 使用图片编辑软件打开图片
   - 另存为 PNG 或 JPG 格式
   - 确保文件扩展名正确（.png 或 .jpg）

3. **验证图片是否损坏**
   - 双击图片文件，看是否能在系统图片查看器中打开
   - 如果无法打开，说明图片文件损坏，需要重新获取

### 问题 3：文件名大小写问题
**症状**：在某些系统上无法加载

**解决方案**：
1. **确保文件名完全匹配**
   - 配置文件中：`cultivation-journey.png`
   - 实际文件名：`cultivation-journey.png`
   - 注意：大小写必须完全一致

2. **统一使用小写**
   - 建议所有文件名都使用小写字母和连字符
   - 例如：`my-game.png` 而不是 `My-Game.PNG`

### 问题 4：文件路径问题
**症状**：控制台显示 404 错误

**解决方案**：
1. **检查文件位置**
   ```
   正确路径：
   TextGame/
   └── Story/data/
       └── covers/
           └── cultivation-journey.png
   ```

2. **检查配置路径**
   ```json
   "cover": "Story/data/covers/cultivation-journey.png"
   ```
   注意：相对于项目根目录（StartGame.html 所在目录）

### 问题 5：图片过大
**症状**：加载缓慢或无法加载

**解决方案**：
1. **压缩图片**
   - 建议文件大小 < 500KB
   - 推荐尺寸：800x800 像素

2. **使用压缩工具**
   - 在线工具：[TinyPNG](https://tinypng.com/)
   - 本地工具：Photoshop "Save for Web"

### 问题 6：透明背景显示异常
**症状**：PNG 透明背景显示为黑色或白色

**解决方案**：
1. 这是正常的，因为卡片背景色是 `#f5f5f5`（浅灰色）
2. 如果需要纯白背景，可以在保存 PNG 时去掉透明度
3. 或者修改 CSS 背景色

## 🛠️ 调试步骤

### 第 1 步：检查控制台
1. 打开 StartGame.html
2. 按 `F12` 打开开发者工具
3. 切换到 `Console` 标签
4. 查看是否有错误信息

**常见错误提示**：
- `404 (Not Found)` - 文件路径错误或文件不存在
- `Failed to load resource` - 文件损坏或格式不支持
- `CORS error` - 跨域问题（需要使用本地服务器）

### 第 2 步：检查网络请求
1. 在开发者工具中切换到 `Network` 标签
2. 刷新页面（F5）
3. 找到 `cultivation-journey.png` 的请求
4. 查看状态码：
   - `200` - 加载成功
   - `404` - 文件未找到
   - `304` - 使用缓存（可能需要清除缓存）

### 第 3 步：直接访问图片
在浏览器地址栏输入：
```
file:///完整路径/TextGame/Story/data/covers/cultivation-journey.png
```
如果能正常显示，说明图片本身没问题，是路径配置问题。

### 第 4 步：替换为测试图片
1. 找一张确定能用的图片（比如其他游戏的封面）
2. 重命名为 `cultivation-journey.png`
3. 替换原文件
4. 刷新页面测试

## ✅ 快速解决方案

```bash

2. 粘贴并重命名为 cultivation-journey.png

```

