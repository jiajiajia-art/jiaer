# 创作者钻石提现 — 计划书（v0.3）

> **日期**：2026-07-20（v0.3 最低提现门槛 ≥1000 钻）  
> **入口**：创作中心「提现」按钮（`Create.tsx`，现为 `withdrawDeveloping` toast）  
> **角色**：`creator`（普通）→ 用户申请升级 → `creator_verified`（创作者激励·官方认证）→ 可提现  
> **关联已有能力**：`withdrawService.js`（半成品）、`userDiamondService.js` + `user_diamond_activities`、`user` 银行卡四字段、`CreatorProfile`、管理后台「用户角色」

---

## 1. 目标

| 角色 | 能力 |
|------|------|
| 官方认证创作者 | 用**钻石**发起提现；10 钻石 = 1 元；积分不可提现 |
| 普通创作者 | 不能提现；可发起「升级为官方认证」申请；可查看审核结果与拒绝说明 |
| 管理员 / 运营 | 「提现管理」+「认证升级」：搜索、审核、导出、**详情时间线** |

**非目标**：自动打款、积分提现、手续费/税率、运营报表（另开）。

## 2. 已锁定业务规则（v0.3）

| # | 规则 | 状态 |

| 9 | 普通创作者点提现 → 引导申请官方认证 | ✅ |

## 4. 状态机与资金

### 4.1 提现单

```
pending ──approve──► approved（审核通过，线下打款）
   │
   └──reject──► rejected（钻石退回 + 流水）
```

### 4.2 钻石（锁定）

1. 申请成功：`deductDiamonds(..., 'withdraw_apply', ..., withdrawNo)`，余额减少  
2. 驳回：`addDiamonds(..., 'withdraw_refund', ..., withdrawNo)`，退回同额  
3. 通过：不再动余额  
4. 并发：`UPDATE user SET diamonds = diamonds - ? WHERE userId = ? AND diamonds >= ?`

### 4.3 快照

创建时写入：`nickname / phone / realName / idCard / bankCard / bankBranch`，打款以快照为准。

### 4.4 管理端「钻石时间线」（详情抽屉/页）

数据源：该用户 `user_diamond_activities` 按 `created_at` 正序/倒序：

| 展示 | 说明 |
|------|------|
| 时间 | created_at（上海时区展示） |
| 类型 | 分成结算 / 充值 / 消费 / **提现申请扣减** / **提现驳回退回** / … |
| 变动 | +/- 钻石数 |
| 说明 | description |
| 关联 | business_id（如提现单号、作品 id） |
| 余额（可选） | 若历史未存 running balance，可只展示变动；P1 可不算滚动余额 |

提现详情页同时展示：快照明文收款信息 + 本单状态流转（申请时间 → 审核时间 → 结果）。

## 5. 用户流程

### 5.1 普通创作者 → 升级

```
点「提现」→ 无权限 →「申请创作者激励（官方认证）」
  → 提交申请（可要求先完善实名+银行卡）
  → 状态：审核中
  → 通过：role = creator_verified，可提现
  → 拒绝：展示 admin_remark，可再次申请（无 pending 时）
```

### 5.2 官方认证 → 提现

```
点「提现」
  → 资料不全 → 引导完善
  → 有 pending → 只展示结算日等待文案
  → 否则弹窗：余额、可提上限 floor(n/10)*10、输入金额（步进 10）、折合人民币
  → 成功 →「审核中，每月15号结算…」
  → 列表：pending / approved / rejected（拒绝可看备注）
```

## 7. API

### 7.1 用户侧

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/auth/withdraw/eligibility` | 角色、资料、pending、余额、`maxWithdrawable`、汇率 |
| POST | `/api/auth/withdraw/create` | 仅 diamonds；倍数校验；扣钻+流水 |
| GET | `/api/auth/withdraw/list` | 我的提现（含 remark） |
| POST | `/api/auth/creator-verify/apply` | 升级申请 |
| GET | `/api/auth/creator-verify/status` | 最新申请状态 + admin_remark |

### 7.2 管理端（`admin` **或** `operator`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/withdraw/list` | 搜索昵称/手机/单号/状态 |
| GET | `/api/admin/withdraw/:id` | 详情：快照明文 + 本单信息 |
| GET | `/api/admin/withdraw/:id/diamond-timeline` | 该用户钻石流水时间线 |
| POST | `/api/admin/withdraw/:id/approve` | 通过 |
| POST | `/api/admin/withdraw/:id/reject` | 驳回+退钻（body.remark 必填建议） |
| GET | `/api/admin/withdraw/export` | Excel/CSV，**卡号身份证明文** |
| GET | `/api/admin/creator-verify/list` | 升级申请列表 |
| POST | `/api/admin/creator-verify/:id/approve` | 通过并升角色 |
| POST | `/api/admin/creator-verify/:id/reject` | 拒绝，`admin_remark` 必填 |

鉴权：与现网 operator 路由一致（`requireOperatorUser` 或等价：operator ∪ admin）。

## 8. 前端

### 8.1 创作中心

- 替换开发中 toast；升级引导 / 完善资料 / 提现弹窗 / 等待文案  
- 提现记录 + 升级申请状态（含拒绝说明）  
- **弹窗记录**：仅展示最近 **5** 条；`pagination.total > 5` 时显示「查看更多」→ 独立页 `/create/withdraw-records`（默认每页 20，后端单页上限 100）  
- 输入校验：≤ maxWithdrawable，`≥ 1000`，且为 10 的倍数  

### 8.2 管理后台

**提现管理**（`/admin/withdraw`）

- 列表列：用户名、手机号、提现钻石、折合元、银行卡、开户行、真实姓名、身份证、状态、操作  
- 列表敏感列可脱敏；**行内「查看」**：明文收款信息 + **钻石时间线**  
- 搜索、筛选、分页、导出 Excel、通过/驳回  

**认证升级**（同页 Tab 或独立栏目）

- 列表 + 通过 / 拒绝（拒绝必填说明）

### 8.3 Excel

字段与列表一致；卡号、身份证为**明文**（打款）；仅 admin/operator 可下。
