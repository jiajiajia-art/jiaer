## 一、本次改了什么

### 1. Romance 编辑器 / 创作壳

- 生成世界向导与完整编辑器：纸面实心白底；**世界生成壳层改为暖浅纯色**，不再铺粉白格子底图（设定页 / 完整编辑器同壳）；酒红 CTA 保留。
- 生图三层提示词：构图收尾句（1:1 / 9:16）改入 `framing`，可编辑主体不再暴露技术参数；画风点选、负面词静默合并。
- 头像库接入风格包筛选（二次元 / 写实 / 墨）；仓库/管理端标签选项同步。
- 云端存档配额按**玩家账号**汇总：普通 10 位、会员 20 位；自动档不占配额；对接文档与前端 `cloudSaves` 同步。
- 草稿冲突选择、手机新手引导、玩法/手机应用对话工坊与 Codex 接入继续补齐。

### 2. 编辑器稳定性（含「编辑器bug优化」）

- 发布前门禁对齐后端：提交审核须具备封面 + 平台题材；缺项拦截并支持跳转补齐；缺封面错误弹窗可「去上传封面」。
- 提审前先同步双封面与题材标签，再调用 publish，减少半开状态 400。
- 存档/草稿字符串清洗与属性引用自愈：打开或恢复草稿时自动 sanitize，保存后生效，降低脏数据拦保存。
- 创作者「继续游玩 / 进预览」路径加固；图片缓存 bust，避免旧图残留。
- 世界题材字段与生成世界向导小修；契约检查补齐发布/自愈/继续游玩相关脚本。

### 3. 平台主站

- 运营消息中心：`/operator/messages`（公告 / 意见反馈 / 定向站内信）；旧 `/operator/feedback` 自动跳转。
- 充值弹窗：地区展示保留；金额写在支付按钮上，不再单独订单摘要；海外支付仅海外 IP。
- 我的玩法 Mod、创作入口、签到/首页/详情等 UI 与契约检查对齐。
- i18n：仓库头像库、管理端资产中心等文案键化。

### 4. 后端（同分支需一并拉取）

- 头像库 `style_pack` 字段 + 迁移；公共/系统上传须带风格包。
- 运营定向站内信表与接口：`/api/operator/direct-messages`（admin 同路径可用）。
- 玩家 AI 线路等相关服务小修。
