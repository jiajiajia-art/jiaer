## 1. 背景与问题

### 1.1 当前实现（基线 → 现状）

| 层 | 基线 | **现况（v0.2）** |
|----|------|------------------|
| 导出落盘 | 单文件 `content.json` | 短篇仍单文件；**≥400 steps 或体积过大 → `step_segments` 分段** + TOC 壳 |
| API | 整包返回 | 无参整包；`?from&limit` / `chapterId` **窗口** |
| 阅读页 | 全量 DOM | meta 阈值决定 **full / window**；≥800 steps **虚拟列表** |
| 目录 | scrollIntoView | 窗口模式先 `ensure` 再跳转；锚点用 **globalStepIndex** |

### 1.2–1.3 / 2–3

（阈值与分层策略同 v0.1，已实现。）

| 指标 | 舒适区 | 窗口 | 虚拟列表 |
|------|--------|------|----------|
| 可见 step 数 | &lt; 400 | ≥ 400 | ≥ 800 |
| 体积 | &lt; 1.5MB | ≥ 1.5MB | — |
| 分段导出 | — | — | step≥400 或 ≥3MB |
