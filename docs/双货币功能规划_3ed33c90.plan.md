## 双货币系统前端功能规划

根据 `docs/双货币流水接口文档.md`，以下是前端需要新增的功能：

---

### 1. 钻石兑换积分功能

**目标**：实现 `POST /api/auth/currency/exchange` 接口调用，10钻石=100积分

**涉及文件**：
- `src/api/account/authApi.ts` - 添加 `exchangeDiamonds` 方法
- `src/api/account/auth.type.ts` - 添加 `ExchangeDiamondsRequest`、`ExchangeDiamondsResponse` 类型
- `src/page/Profile.tsx` - 在"我的钻石"卡片区域添加兑换入口按钮
- `src/components/Purchase/ExchangeModal.tsx` - 新建兑换弹窗组件（输入钻石数量，1颗起兑）
- `src/i18n/locales/zh.json` / `en.json` - 添加兑换相关文案

**兑换弹窗交互逻辑**：
- 输入框限制只能输入10的倍数
- 实时显示可获得的积分数量
- 提交后调用接口，成功后刷新用户信息

---

### 2. 钻石明细页面

**目标**：创建独立的钻石流水页面，与现有积分明细页面 `PointsDetails.tsx` 对应

**涉及文件**：
- `src/page/DiamondsDetails.tsx` - 新建（参考 `PointsDetails.tsx` 结构）
- `src/page/DiamondsDetails.module.css` - 新建
- `src/api/account/authApi.ts` - `getPointsActivities` 已有支持，调用时传 `currency='diamonds'`
- `src/router/index.tsx` - 添加路由 `/diamonds/details`
- `src/i18n/locales/zh.json` / `en.json` - 添加文案

**页面逻辑**：
- 调用 `getPointsActivities({ currency: 'diamonds' })`
- 展示当前钻石余额
- 流水列表支持收入/支出筛选、年月份筛选、分页加载
- 流水项使用 `amount` 字段（而非 `points`）
- 点击返回按钮回退

---

### 3. 联合流水页面（我的资产）

**目标**：创建"我的资产"页面，同时展示积分和钻石两种流水的合并视图

**涉及文件**：
- `src/page/AssetDetails.tsx` - 新建（合并积分+钻石流水）
- `src/page/AssetDetails.module.css` - 新建
- `src/router/index.tsx` - 添加路由 `/asset/details`
- `src/i18n/locales/zh.json` / `en.json` - 添加文案

**页面设计**：
- 顶部显示当前积分和钻石余额
- Tab 切换：全部 / 积分 / 钻石
- 流水列表按时间合并排序（最新在前）
- 每条流水根据 `type` 字段区分显示（积分用 `points`，钻石用 `amount`）
- 支持收入/支出方向筛选（两个 Tab 下都可用）
- 分页使用各自的分页信息（`pointsPagination` / `diamondsPagination`）

---

### 4. Profile 页面调整

**涉及文件**：
- `src/page/Profile.tsx` - 将"我的钻石"入口的点击跳转从 `/points/details` 改为 `/asset/details`（或保留 `/diamonds/details`）
- 添加兑换按钮到钻石卡片区域

---

### 5. 路由配置

**涉及文件**：
- `src/router/index.tsx` - 添加：
  - `/asset/details` - 我的资产（联合流水）
  - `/diamonds/details` - 钻石明细
