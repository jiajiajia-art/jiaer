# 生活开销包 · 设计文档

> 扩展包 id：`pack-living`（内置，娱乐圈 · 星光2005 默认勾选）
> 相关代码：`src/game/data.ts`（`RAW_MEALS` / `MEALS` / `mealOf` / `ENT_BILLS` / `billsFor` / `bankruptLineFor`）、`src/game/logic.ts`（周结算）、`src/components/ScheduleBoard.tsx`（「本周伙食」选择）、`src/mods/entPacks.ts`（扩展包定义）

---

## 1. 一句话

**每周吃什么，玩家自己选**——泡面省钱伤身，轻食私厨养人但花钱；再加上随名气分档的住行开销：新人住小公寓，越红住得越好也越贵。

**没挂这个包的世界，就没有生活开销。** 引擎不再给所有世界兜底扣「生活费 + 房租」。

---

## 2. 设计目标

| 问题（改造前） | 现在的做法 |
| --- | --- |
| 所有世界都被扣一份通用生活费（每周 ¥1,000 + 每 4 周 ¥3,000），哪怕这个世界根本不需要经济压力 | 生活开销做成扩展包，**挂了才有**；世界自己写了 `bills` 的（如校园的饭卡）照常生效 |
| 吃饭是账单里固定的一行「餐饮美食」，玩家没得选 | 吃饭变成每周一次的**生活方式选择**：花多少钱、换来什么身体状态，由玩家权衡 |
| 新人一开局就付星光级账单 | 住行账单按名气分档，新人只付普通开销 |

设计原则：

1. **选择要有代价也有回报**：便宜的伤身体 / 加压力，贵的养体能 / 气色或减压，没有「最优解」。
2. **一次选好，一直沿用**：不用每周操心，想换随时在日程板改。
3. **吃不起不卡死**：钱不够时当周自动降档，并在周报里提示，不会因为伙食直接把人逼破产。
4. **只给需要的世界**：经济压力是玩法，不是所有世界的默认设定。

## 3. 每周吃什么（核心）

### 3.1 伙食档位（娱乐圈标准）

| 伙食 | 每周伙食费 | 每周效果 | 门槛 | 定位 |
| --- | --- | --- | --- | --- |
| 泡面速冻 | ¥300 | 体能 -1 · 造型 -1 · 压力 +3 | — | 极限省钱，伤身又憋屈 |
| **家常自炊**（默认） | ¥1,500 | 体能 +1 · 压力 -1 | — | 踏实养人，性价比之选 |
| 外卖快餐 | ¥2,500 | 体能 -1 · 压力 -3 | — | 省时省心，但油盐偏重 |
| 健身轻食 | ¥4,000 | 体能 +2 · 造型 +2 · 压力 +2 | — | 塑形上镜，代价是嘴馋 |
| 下馆子 | ¥6,000 | 压力 -6 | — | 花钱买心情 |
| 营养师私厨 | ¥12,000 | 体能 +3 · 造型 +3 · 压力 -2 | 名气 ≥ 150 | 上升艺人以后才请得到 |

- 「造型」即 `styling`，参与容貌计算（容貌 = 仪态 × 0.55 + 自信 × 0.25 + 造型 × 0.2）。
- 每周的效果量级刻意比课程小（一节形体课 = 仪态 +3~5），伙食是**长期慢慢积累**的背景加成，不替代训练。

### 3.2 玩家操作

- 入口：**本周日程**弹窗 → 「本周伙食」卡片（只有挂了生活开销包的世界才显示）。
- 点选即生效，存进本局存档（`sim.meal`），之后每周沿用，直到玩家改掉。
- 没解锁的档位置灰，显示「未解锁：名气 ≥ 150」。
- 没选过 → 默认「家常自炊」（`default: true`；没有默认档时取第一档）。

### 3.3 周日结算

1. 取玩家所选伙食；已失效（门槛不再满足）或**当前资金付不起** → 当周改吃**付得起的最贵一档**；一档都付不起（已透支）→ 吃最便宜的一档。降档时周报提示「钱不够吃「X」，这周只能改吃「Y」」。玩家的选择本身不变，下周钱够了自动恢复。
2. 账单追加一行「伙食 · {名称}」，和住行账单一起扣费（属于被动扣费，允许透支）。
3. 结算效果：压力、能力（按能力上下限截断）、造型（0~999）。
4. 新手缓冲期（`economy.graceWeeks`）同样对伙食费打折。

## 4. 住行账单（按名气分档）

名气达到门槛即进入该档，取已达到的最高一档；名气 300 以上不再加码。吃饭已经单独拿出去，这里只剩住和形象开销。

| 档位 | 名气 | 每周 | 每 4 周追加 | 4 周住行合计 | 加「家常自炊」后折合每周 |
| --- | --- | --- | --- | --- | --- |
| 无名新人 | 0 – 49 | 生活起居 ¥3,000 | 公寓房租 ¥8,000 | ¥20,000 | ≈ ¥6,500 |
| 小有水花 | 50 – 149 | 生活起居 ¥4,000 | 房租 ¥12,000 · 形象打理 ¥3,000 | ¥31,000 | ≈ ¥9,250 |
| 上升艺人 | 150 – 299 | 生活起居 ¥7,000 | 房租 ¥20,000 · 形象宣传 ¥8,000 | ¥56,000 | ≈ ¥15,500 |
| 当红艺人 | ≥ 300 | 生活起居 ¥12,000 | 房租 ¥35,000 · 形象宣传 ¥15,000 | ¥98,000 | ≈ ¥26,000 |

开局资金 ¥5,000：第一周住行 ¥3,000 + 伙食 ¥1,500 刚好付得起；第 4 周月末加房租是第一个资金压力点。

## 5. 破产线

破产线 = （本档每周住行 + 本周伙食费）× 28，夹在 ¥500 ~ ¥500,000 之间，可用 `economy.bankruptLine` 直接指定。

- 吃得越好、住得越好，能承受的负债越深（信用更好）。
- **完全没有生活开销的世界**按每周 ¥1,000 折算（≈ ¥28,000），只有违约金、事件扣费会让人透支，不会因为没有账单导致破产线过低。

## 6. 哪些世界有生活开销

| 世界 | 有没有 | 说明 |
| --- | --- | --- |
| 娱乐圈 · 星光2005 | 有（默认勾选生活开销包） | 老存档读档时自动补上这个包，体验连续；游戏中也可以在模组管理里关掉 |
| 校园 | 只有校园自己写的饭卡 / 住宿杂费 | 没挂生活开销包，没有「每周吃什么」；金额量级差太多（校园每周 ¥80），**不建议直接挂** |
| 自建世界（没写 `bills`） | 没有 | 想要经济压力，就挂生活开销包或自己写 `bills` / `meals` |
| 自建世界（写了 `bills`） | 有，按作者写的 | 挂上生活开销包会整份替换作者的住行账单 |

## 7. 数据结构（给模组作者）

```ts
type MealPlan = {
  id: string;
  name: string;
  desc?: string;
  cost: number;                                // 每周伙食费
  stress?: number;                             // 每周压力变化（负 = 减压）
  gain?: Partial<Record<StatKey, number>>;     // 每周能力变化，可为负
  styling?: number;                            // 每周造型变化
  reqs?: { metric: string; min: number }[];    // 解锁门槛（fame / reputation / money / stat:键 / c:自定义属性）
  default?: boolean;                           // 未选择时的默认档
};

type BillsSlot = {
  weekly?: BillLine[]; monthly?: BillLine[];   // 最低档
  tiers?: { minFame: number; label?: string; weekly?: BillLine[]; monthly?: BillLine[] }[];
};
```

- 内容槽：`meals`（数组，按 id 合并）、`bills`（对象，浅合并）。
- 校验：`meals[i]` 必须有 `name` 与数字 `cost`；`bills.tiers[i].minFame` 必须是数字。
- 某档省略 `monthly` 会回退到顶层 `monthly`；`weekly` 同理。
- 创意工坊 AI 的字段说明已加入 `meals` 与 `bills.tiers`，可以直接用自然语言让 AI 生成。

小额世界示例（校园风格，自己写，不挂包）：

```json
{
  "meals": [
    { "id": "canteen", "name": "食堂套餐", "cost": 60, "default": true, "gain": { "tineng": 1 } },
    { "id": "snack", "name": "零食当饭", "cost": 30, "stress": 2, "gain": { "tineng": -1 } },
    { "id": "treat", "name": "校门口小馆", "cost": 120, "stress": -4 }
  ]
}
```

## 8. 验证

- 类型检查通过。
- 周结算脚本抽查：
  - 娱乐圈默认：生活起居 ¥3,000 + 月末房租 ¥8,000 + 伙食·家常自炊 ¥1,500。
  - 选「营养师私厨」但名气不足 / 钱不够：当周自动改吃付得起的「健身轻食」。
  - 关掉生活开销包：账单为空，资金不变。
  - 校园（无包）：只扣校园自己的饭卡与住宿杂费。
- 上一轮 28 局两年模拟是在旧账单（含固定「餐饮美食」）下跑的；现在默认伙食 ¥1,500 比原来新人档的餐饮 ¥2,000 略低，整体压力略小。调整金额后建议复跑一轮，重点看**破产局数**和**首次透支的周数**。

## 9. 待定

- **游戏内档位明细**：账单卡片还没显示「当前住行档位 / 下一档门槛」。`billsFor` 已返回档名，可直接接 UI。
- **伙食与剧情联动**：目前伙食只影响数值，还没告诉 AI 主角这周吃什么；可以把当前伙食写进 AI 上下文，让剧情里出现「又在吃泡面」「私厨送餐」之类的细节。
- **体面成本**：名气很高还天天吃泡面，可以考虑被狗仔拍到、口碑小幅波动等事件，用固定事件配合 `sim.meal` 实现。
