# 画风示例图

文件名 = 画风 id，竖版 3:4，建议 600×800 的 webp：

vn.webp（日系视觉小说）· otome.webp（乙女向）· dark.webp（暗黑幻想）· guofeng.webp（古风水彩）
anime.webp（日系动漫）· manhua.webp（国漫厚涂）· chibi.webp（Q版萌系）· cyber.webp（赛博动漫）· pixel.webp（像素风）

没放图时选择器显示色块；创作者用某画风生成过图后，本机会自动拿最近一张当示例。
预设定义见 `src/lib/editorImagePrompts.ts` 的 `ART_STYLE_PRESETS`。
